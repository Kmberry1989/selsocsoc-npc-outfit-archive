# Selfie Social Society — NPC Outfit Archive

Archived **grayscale** one-piece NPC outfits (v1) from the main game repo.
These were authored for the multiplicative tint renderer and were superseded
by pre-colored outfits. Kept here for reference; not used by the game.

- 13 NPCs: mayor-mayor, gideon, lyla-lens, chip-chance, barnaby-bargain,
  pip-parade, agnes-alley, dottie-daly, peggy-plank, mr-buck-coinsworth,
  fern-bramble, stanley-stamp, bobby-gill
- Format: grayscale PNG, 4-view character sheet
- The live game uses colored outfits in `assets/npc-outfits/` of
  [selsocsoc](https://github.com/Kmberry1989/selsocsoc) (untinted).

## Player outfits v1 (archived 2026-10-15)

Archived **grayscale** player outfits from the main game repo
(`assets/outfit-textures/`), superseded by flat-fabric monochrome restyles.
These were photographic-style grayscale for the multiplicative tint renderer.

- 33 outfits in `player-outfits-v1/` + the v1 `manifest.json`
  (with each outfit's signature default tint)
- Format: grayscale PNG, 1024x1024, 4 vertical strips
  (FRONT | RIGHT | BACK | LEFT per `assets/outfit-textures.js` atlasBands)
